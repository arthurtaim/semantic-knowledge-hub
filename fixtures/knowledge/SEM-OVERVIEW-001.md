# Semantic Knowledge Hub — обзор демо-продукта

**ДЕМО-ДАННЫЕ.** Синтетический документ о самом приложении; он не описывает системы или процессы банка.

## Назначение
Приложение помогает команде семантического слоя находить документацию, задавать вопросы по базе знаний и предлагать изменения через проверяемый процесс ревью.

## Источники знаний
- Каноническая база знаний команды хранится в отдельном репозитории GitLab.
- Корпоративная документация читается из Confluence Data Center через утверждённый MCP-коннектор только для чтения.
- В демо-режиме используется локальный workspace с синтетическими документами; GitLab и Confluence не подключены.

## Статусы документов
Каждый документ имеет статус: draft, in_review, approved или deprecated. Ассистент по умолчанию опирается только на утверждённые документы (approved).
