# Semantic Layer — demonstration architecture

**DEMO ONLY. This page contains fictional example content and does not describe the bank.**

This local demonstration models a knowledge base with four layers: a document repository, an indexing service, a search API and a user interface. These are application concepts for demo/testing, not statements about corporate architecture.

## Principles
- A document always has a stable ID and an approval status.
- Search results reference their source document.
- Suggested changes require human review.
