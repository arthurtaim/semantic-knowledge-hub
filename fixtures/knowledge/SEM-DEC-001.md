# ADR-демо — локальный полнотекстовый поиск на SQLite FTS5

**ДЕМО-ДАННЫЕ.** Пример записи архитектурного решения для самого приложения.

## Контекст
Для локального MVP нужен воспроизводимый поиск без внешних сервисов и без сетевого доступа.

## Решение
Для локального поиска выбран SQLite FTS5: индекс строится из Markdown-документов и в любой момент может быть перестроен. Векторная база данных в MVP не используется.

## Последствия
Поиск лексический: синонимы и перевод между языками не распознаются. Индекс не является источником истины.
