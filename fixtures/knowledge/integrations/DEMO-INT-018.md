# Ночная полная выгрузка ARIS (устаревший поток)

> Синтетический демо-документ: описывает вымышленную учебную модель, не системы банка.

> **Статус: deprecated.** Поток выведен из учебной модели и заменён инкрементальным потоком
> ARIS → Catalog (DEMO-INT-001). Не используйте этот документ для настройки, проверки или ответов о
> действующем порядке загрузки ARIS. Он сохранён только для истории.

## Назначение

Документ описывал прежний способ доставки процессных метаданных ARIS в каталог: одну ночную полную
выгрузку всех объектов ARIS. Описание оставлено, чтобы было понятно, откуда в старых материалах берутся
упоминания ночного экспорта в 03:00, и почему они больше не верны.

## Источник и получатель

Источник — ARIS (`SYS-ARIS`), получатель — каталог (`SYS-CAT`). Те же системы обслуживает действующий
поток DEMO-INT-001.

## Входные данные (Inputs)

Полный экспорт всех объектов ARIS одним файлом с полями `aris_object_guid`, `aris_object_name`,
`aris_model_path`, `aris_owner_role`, `aris_last_change`, `aris_status`. Отбора по времени изменения не было.

## Выходные данные (Outputs)

Все записи ARIS в каталоге каждую ночь заменялись целиком содержимым нового экспорта.

## Правила преобразования (Transformation Rules)

1. Выгрузка запускалась ежедневно в 03:00 (условное время).
2. Перед загрузкой из каталога удалялись все записи ARIS, затем загружался новый файл.
3. Ключ идемпотентности не применялся: повторный запуск выгрузки просто повторял полную замену.

## Ограничения (Constraints)

Именно ограничения привели к замене потока:

- Данные каталога по ARIS могли быть старше суток: изменение, сделанное в 03:05, появлялось только
  следующей ночью. Требование актуальности датасета Process Overview (не старше 12 ч) таким потоком
  не выполнялось.
- Каждая выгрузка нагружала ARIS полным объёмом, даже если за сутки изменилось несколько объектов.
- Между удалением и загрузкой каталог временно не содержал записей ARIS.
- При сбое ночного запуска повтор происходил только следующей ночью.

## Ошибки и обработка (Error Cases)

Отдельной обработки ошибок, кодов и очереди недоставленных сообщений у потока не было: сбой фиксировался
в журнале запуска, а данные оставались в состоянии предыдущей ночи. Действующие правила обработки ошибок
относятся только к новым потокам.

## Версия и статус

Последняя версия 1.6, статус deprecated с 2025-12-10. Заменён потоком DEMO-INT-001, который объявляет
связь `supersedes` на этот документ. Восстанавливать поток, ссылаться на него в новых интеграциях или
сочетать его с действующим расписанием запрещено.

## Пример

В старой инструкции сказано: «данные ARIS обновляются ночью в 03:00». Это утверждение устарело. Для
ответа о текущем порядке нужно открыть DEMO-INT-001: метаданные ARIS доставляются в каталог
инкрементально по утверждённому расписанию, а не полной ночной выгрузкой.
