- убрано повышение ревизии плана при применении WCP → падает `test_wcp01_to_04_…`;
- включён поиск по базе знаний в анализе проекта → падает `test_an01_…[claude]`;
- отказ архивного проекта убран из `resolve` → тест `test_reg06_…` проходит: второй слой (`planning_context` в
  `WorkAiService`) тоже отдаёт 409 до вызова модели. Защита двухслойная, тест проверяет общий результат.
