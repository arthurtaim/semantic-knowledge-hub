## Что сделано, простыми словами

Раньше на вопрос «Сколько документов в базе?» ассистент искал слова «документ» и «база» в тексте документов и либо
цитировал случайный абзац, либо отказывался: у модели не было доступа к реестру, а доказательством считалась только
цитата из документа.

Теперь модель может сама попросить у сервера проверить данные системы — каталог документов (числа, списки,
метаданные), поиск по содержимому, граф связей, реестр шаблонов — и, если у пользователя есть право, подготовить
предложение черновика. Сервер выполняет только разрешённые инструменты, со строгой проверкой параметров, в границах
того, что видит этот пользователь, с лимитами по шагам и времени. Числа приходят из реестра, а не из текста модели.
Классификатора намерений и правил по ключевым словам в продукте нет: модель сама решает, что проверить.

В интерфейсе (минимальные изменения UI v2):

- под ответом появился блок **«Данные системы SKH»**: «По данным реестра SKH — Документы в доступном каталоге SKH»,
  крупно **«83 документа»** (значение берётся из ответа сервера, а не из текста модели), какие фильтры реально
  применены («Фильтр: статус: утверждён · тег: aris»; совпадение по тексту прямо названо так и не выдаётся за тег),
  область («доступный вам каталог»), срез индекса и время, список документов ссылками, «Показаны первые 5 из 83»;
- метка `[F1]` в тексте стала ссылкой **«С1»** (с рамкой — цитаты документов остаются заливными 1 / К1 / Ф1); по
  наведению или фокусу — подсказка, по Enter или клику — переход к карточке;
- цитаты документов, группы «Документы команды / Корпоративные / Вложения» — без изменений и отдельно от данных
  системы;
- ответ из общих знаний помечен тихой меткой **«Общие знания, не данные SKH»**;
- честные состояния: «недоступно», «нет ответа вовремя», «нет доступа», «не найдено в доступной области» и «ноль»
  выглядят по-разному; если проверить не удалось, ассистент пишет **«Не удалось проверить данные системы»**, а не
  «В базе знаний нет ответа» со случайными похожими документами;
- уточняющий вопрос «А сколько из них утверждено?» помнит, о каких документах шла речь (браузер отправляет серверу
  «референт» прошлого ответа, сервер перепроверяет доступ);
- при потоковом ответе каждый новый раунд модели начинает предварительный текст заново, а одна короткая строка
  показывает, что проверяется («Проверяю каталог…», «Ищу в документах…», «Смотрю граф связей…», «Смотрю шаблоны…»);
- предложение черновика из диалога показывается существующей карточкой предложения; ничего не применяется без
  «Принять».

Демо-режим (`mock`) не изменился: он не понимает язык и инструментами не пользуется — на вопрос о числе документов
он по-прежнему отвечает выдержками; для таких вопросов нужна модель или страница каталога.

## Риски безопасности

- **Открытый публичный стенд без входа = нет персональной идентичности.** Все посетители — один и тот же
  пользователь сервера; инструменты видят ровно то, что видит эта единственная идентичность. Персональных прав
  доступа на таком стенде нет и не придумывалось. Значит, на нём допустимы только синтетические данные. Режим
  `AUTH_MODE=local_demo` рассчитан на loopback и закрывается при внешнем адресе — публичный доступ держится на
  настройках прокси, это риск, требующий осознанного решения.
- **Личный Claude CLI** — только для синтетики; корпоративные данные туда не отправлять. Воркер по-прежнему
  запускается без инструментов, MCP и доступа к файлам; инструменты SKH выполняет только наш сервер.
- **Внедрённые инструкции в документах и вложениях** обрабатываются как данные (маскируются, не исполняются); JSON
  внутри документов или ответов инструментов никогда не считается вызовом. Это проверено тестами, но против
  настоящей модели не испытано.
- **Референт уточнений приходит от браузера** — сервер выбрасывает ID, которые пользователь больше не видит, и каждый
  вызов перепроверяет доступ; референт не даёт прав.
- **Индекс полнотекстового поиска общий** для читателей одного развёртывания; инструменты всегда пересекают
  результаты со снимком читателя (покрыто тестами утечек).
- Логи содержат только технические метаданные (инструмент, исход, время, количество), без вопросов, фрагментов и
  ответов модели.
