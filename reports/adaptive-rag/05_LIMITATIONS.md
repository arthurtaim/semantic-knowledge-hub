# 05 — Ограничения, риски, стоимость, откат

## 2. Цена и риски

- **+1 вызов модели** на каждый вопрос «Оба», где есть локальные фрагменты (≈ 4,4–5,2 тыс. символов запроса, ответ —
  короткий JSON). Не вызывается для `team`, `corporate`, `search_external`, вопросов без локальных фрагментов и для
  mock/disabled. Время ограничено `EXTERNAL_GATE_TIMEOUT_SECONDS` (20 с, repair включён).
- **До 2 MCP-поисков** вместо 1 для вопроса из двух аспектов; загрузки, фрагменты, символы и дедлайн — общие, как
  раньше. На holdout у oracle внешних поисков больше (24 против 15 у правила v2), загрузок не больше (15 против 17).
- **Ложное «need_external»** (лишний вызов): в основном там, где локальный поиск не принёс факт; ограничено бюджетом
  частоты (30 поисков на 10 минут на ACL-scope по умолчанию).
- **Ложное «sufficient»** (пропуск): главный риск слабой модели, см. §1.
- **Порог фрагмента** для фокусного поиска мягче (заголовок страницы считается предметом раздела), но раздел обязан
  сам содержать слово запроса; поиск целым вопросом не изменён.
- **Политика инструментов** `TOOL_POLICY.md` → версия 5 (одна строка: инструмента Confluence нет, решение принято
  сервером, неподтверждённое называть неподтверждённым).

## 3. Ограничения проверки

- Только синтетический корпус (83 документа, 24 страницы mock Confluence + сгенерированный шум). На реальном
  Confluence распределения слов, размер и шум другие.
- Решения модели — только scripted-двойники: `TARGET_MODEL_NOT_VALIDATED`, `LIVE_LLM_NOT_TESTED`.
- Выборка 40 вопросов: разница в 1–2 кейса — в пределах шума.
- Задержка — внутрипроцессный замер на Apple M5 без времени модели, не Hetzner и не целевой контур.
- Holdout: один прогон после заморозки `1fdc682`; разбор ошибок AG-002, AG-040 прочитан после прогона — для
  следующих правок, нацеленных на эти случаи, нужен новый holdout.
- E2E — против изолированных офлайн-стендов и loopback test doubles (GitLab, Confluence MCP/REST, scripted-модель).

## 4. Основания для остановки или отката

Откатить (`EXTERNAL_GATE=lexical`, без релиза кода), если на целевой модели:
- невалидные цитаты или утечки > 0;
- ложное «sufficient» при данном контексте заметно хуже правила v2 на тех же вопросах;
- доля invalid/timeout такова, что ответы почти всегда идут по резервному правилу (тогда ворота — чистая стоимость);
- p95 вызова ворот неприемлем для пользователей «Оба».
