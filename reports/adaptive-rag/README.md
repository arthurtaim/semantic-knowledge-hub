## Что сделано

Для «Оба» решение «идти ли в Confluence» принимает **local-first evidence gate**: одно короткое решение модели через
обычный chat completion (`sufficient` / `need_external` / `uncertain`, компактный JSON, ≤ 1 repair), всё остальное —
сервер: режим источников, статусы и ACL, проверка evidence-id и идентификаторов вопроса, безопасность и число
запросов (≤ 2), лимиты MCP, бюджет частоты, видимый fallback на прежнее правило v2. Внешний поиск идёт **по пробелу**,
а не целым вопросом. `/ask`, `/ask/stream` и tool loop используют одну подготовку — одно решение и одни и те же вызовы.
Mock-провайдер остаётся на правиле v2 (ничего «семантического» не симулируется), поэтому gold-оценка не изменилась.
