# «Создать задачу» из чата и даты из запроса — отчёт

Ветка `feature/skh-chat-create-task` от `main` `5846bf0`. Дизайн:
`docs/superpowers/specs/2026-11-27-chat-create-task-design.md`, план: `docs/superpowers/plans/2026-11-27-chat-create-task.md`,
описание: `docs/WORK_CHAT_SKILLS.md` §12, ADR-049, API v0.10. Модель во всех проверках — только скриптовый двойник
(`backend/tests/support/scripted_model.py`); живых и платных вызовов не было. Push, merge и deploy не выполнялись.

## Что сделано

- **Навык «Создать задачу»** (`create_task`). Человек выбирает его сам, или сервер запускает его по фразе «создай /
  заведи / добавь / поставь / оформи … задачу …» (`app/domain/task_intent.py`, без модели). Вопросы, множественное
  число, списки, вложенные файлы, явный навык и отсутствие прав дают обычный ответ.
- **Черновик** (`app/work/drafts.py`). Сервер сам извлекает даты, проект, исполнителя (с учётом падежа) и приоритет.
  Модель (протокол `adapters/ai/task_draft_protocol.py`, `openai_compatible` и `claude_cli`) предлагает название и
  описание и только цитирует даты; цитата проверяется по фразе, дату разбирает сервер (`app/domain/ru_dates.py`).
  Без модели навык работает на серверном извлечении.
- **Карточка** (`frontend/src/components/AskTaskDraft.tsx`). Метки происхождения полей, подсветка недостающего,
  «Создать задачу» обычным `POST /api/projects/{key}/tasks` (один запрос на двойной клик), связь с документами
  контекста, «Ответить как обычно» на автозапуске. Слова в чате ничего не создают.
- **Даты в навыке «Составить план задач».** Промпт просит дословные цитаты дат; сервер сохраняет срок задачи,
  закреплённый период (`date_locked`, преемники встают после него) и начало плана. В проверке плана — «Срок» и «Даты
  закреплены (из вашего запроса)» со «Снять закрепление».
- **Политика ассистента** `TOOL_POLICY.md` версии 7.

## Решения, принятые при реализации

- Дата без маркера («сделать X 5 декабря») считается сроком; числовая дата требует двузначного месяца («2.1» —
  версия, не дата).
- Между глаголом и «задачу» допускаются только служебные слова и латинский ключ проекта (иначе «создай документ про
  задачу» запускал бы навык).
- Основа имени: последняя буква отбрасывается у частей до 5 букв, две — у длинных, не короче 3 («Анне» → «Анна»).
- Подсказка исполнителя от модели показывается, только если это фрагмент фразы.
- «Сегодня» для дат черновика — часовой пояс модуля по умолчанию (проект может быть ещё не выбран).
- Начало плана из запроса становится плановым началом, если человек его не выбрал (`suggested_start` — для метки).
- Связь с документом ревизию не передаёт: сервер записывает ревизию, которую видит в момент связи (инвариант M6).
- Карточка показывает открытые проекты из `/api/projects`; права на конкретный проект проверяются при создании
  (403 → «Нет прав на создание задач в этом проекте.»).

## Риски и ограничения

- Живая модель не проверялась: качество названий, описаний и цитат реальной модели не измерено.
- Распознавание дат покрывает перечисленные форматы; «до конца месяца», «на следующей неделе» не распознаются — поле
  остаётся пустым, человек выбирает дату в карточке.
- Состояние «задача создана» после повторного открытия диалога не хранится: карточка снова показывает кнопку, повторный
  клик в течение 7 дней возвращает ту же задачу (идемпотентность), позже создал бы вторую.
- Новых таблиц и миграций нет; откат — только код.
