# Что запрещает промышленное использование

Этот список удаляется по пунктам — только когда ограничение устранено **и проверено** (тест, протокол
проверки или решение ИБ со ссылкой). До этого приложение — однопользовательский инструмент на
синтетических данных или в изолированном тестовом контуре.

Обновлено для M4.6/M4/M5 (2026-11-23): создание документов, профили запуска, публикация в Confluence DC.
Всё внешнее проверено только на тестовых дублях; live validation не проводилась.

## Что уже сделано, чтобы блокеры не обошли случайно
- `AUTH_MODE=local_demo` отказывается стартовать на нелокальном интерфейсе, с нелокальными `ALLOWED_HOSTS`, CORS или `APP_PUBLIC_URL`.
- `AUTH_MODE=sso` отказывается стартовать, пока SSO/RBAC не реализованы. Открытого режима «для всех» нет.
- Каждый API-маршрут объявляет действие (`require(Action…)`); тест не даёт добавить маршрут без него.
  Политика `DenyAllPolicy` проверена на всех маршрутах. Публикация разделена на `prepare_publication`
  (только чтение) и `publish_confluence` (запись).
- `http` разрешён только для loopback-адресов и объявленных тестовых дублей; TLS для реальных хостов не отключается.
- Профиль запуска (`INTEGRATION_PROFILE`) ограничивает цели и запись: в `offline` интеграции запрещены;
  `integration_mock` адресует только объявленные дубли (`MOCK_SERVICE_HOSTS`: loopback, `*.example`/`*.test`/
  `*.invalid`/`*.localhost`, `<name>-mock`); `live_read_only` запрещает любую запись; `live_write_staging`
  требует для записи в Confluence `CONFLUENCE_PUBLISH_STAGING_ACK`, равный ключу пространства, и корпоративный CA.
- Запись в Confluence (`CONFLUENCE_PUBLISH_ENABLED=true`) вне `integration_mock`/`live_write_staging` блокирует старт.
- Токен публикации обязан отличаться от токена MCP; пространство и родитель — только из конфигурации; ни один
  маршрут не принимает page ID; `confluence_page_id` во frontmatter игнорируется.
- Публикуется только ревизия, которую GitLab подтверждает как смёрженную через MR; dry-run выполняет только
  чтение; публикация — отдельное явное действие; чужие и вручную изменённые страницы не перезаписываются
  автоматически.
- AI-черновик не может получить статус `approved`, не хранится и проходит тот же путь ревью и MR.
