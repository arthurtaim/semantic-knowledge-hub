# Что запрещает промышленное использование

Этот список удаляется по пунктам — только когда ограничение устранено **и проверено** (тест, протокол
проверки или решение ИБ со ссылкой). До этого приложение — однопользовательский инструмент на
синтетических данных или в изолированном тестовом контуре.

| # | Блокер | Последствие сейчас | Что нужно для снятия |
|---|---|---|---|
| PB-01 | **Нет SSO и аутентификации пользователей.** `AUTH_MODE=sso` отказывается запускаться; `local_demo` — один оператор и только loopback | Нельзя дать доступ второму человеку | Интеграция с корпоративным IdP (OIDC/SAML через reverse proxy), тесты отказов, ревью ИБ — `docs/SSO_RBAC_REQUIREMENTS.md` |
| PB-02 | **Нет RBAC.** `LocalDemoPolicy` разрешает единственному оператору все действия | Любой, кто получит доступ к порту, может всё | Политика ролей поверх `app/authz.py` (точки уже размечены и покрыты тестами) |
| PB-03 | **Нет пользовательских ACL GitLab.** Чтение одной сервисной учётной записью, общий индекс | Документ, закрытый для пользователя в GitLab, будет ему показан | Чтение от имени пользователя или проверка прав на каждый документ; разделение индекса по правам |
| PB-04 | **Нет пользовательских ACL Confluence.** MCP вызывается с общим сервисным токеном (`CONFLUENCE_MCP_AUTH_MODEL=service_account`) | Страницы, закрытые для пользователя, могут попасть в ответ | MCP с передачей пользовательской идентичности или проверка прав на страницу; `per_user` сейчас блокируется при старте |
| PB-05 | **Интеграции проверены только на mock и replay.** GitLab — на тестовом дубле, Confluence MCP — на записанных синтетических сценариях | Неизвестно поведение реального GitLab и MCP банка на ошибках, пагинации, лимитах | Этап M4 Live Validation по `docs/STAGING_TEST_RUNBOOK.md`, протокол результатов |
| PB-06 | **Нет утверждённых сетевых политик.** Allowlist в приложении не заменяет межсетевой экран | Ошибка конфигурации может открыть лишний egress | Правила egress только к GitLab, MCP и AI (443), согласованные с ИБ; проверка с хоста |
| PB-07 | **Нет правил аудита.** Аудит предложений — локальная SQLite без содержимого; входы и чтения не журналируются | Нельзя расследовать доступ к документам | Требования ИБ к журналам: события, хранение, доставка в SIEM, защита от изменения |
| PB-08 | **Не согласовано хранение журналов и данных.** `workspace/` (индекс и предложения с текстом документов) — локальный том без шифрования и бэкапа | Копии документов вне GitLab | Решение о хранении, шифровании, сроках, удалении; бэкап или осознанный отказ (индекс восстанавливаем) |
| PB-09 | **Нет утверждённого AI-провайдера.** Работает только `mock`; `internal_api` не проверялся на реальном эндпоинте; GigaCode не подключён | Ответы — дословные выдержки, без генерации | Решение о модели, ревью промптов и injection-защиты, нагрузочный тест, `docs/GIGACODE_MIGRATION.md` |
| PB-10 | **Нет фонового планировщика синхронизации и мониторинга.** Синхронизация идёт при обращении к данным | Устаревание индекса видно только в интерфейсе | Метрики и алерты (сбой синхронизации, ошибки GitLab/MCP), healthcheck зависимостей |
| PB-11 | **Нет HA и масштабирования.** Один процесс, SQLite, кэш в памяти | Недоступность при сбое, нельзя запустить несколько реплик | Решение о целевой архитектуре (PostgreSQL/общий индекс либо осознанный single-instance) |
| PB-12 | **Публикация в Confluence (M5) не реализована** и заблокирована при старте | — | Отдельный этап после проверки GitLab и MCP |
| PB-13 | **Нет процедуры поставки и обновления** (подпись образов, сканирование зависимостей, внутренний registry) | Образы собираются из публичных базовых образов | Корпоративный CI/CD, сканирование, внутренние зеркала pip/npm/Docker |

## Что уже сделано, чтобы блокеры не обошли случайно
- `AUTH_MODE=local_demo` отказывается стартовать на нелокальном интерфейсе, с нелокальными `ALLOWED_HOSTS`, CORS или `APP_PUBLIC_URL`.
- `AUTH_MODE=sso` отказывается стартовать, пока SSO/RBAC не реализованы. Открытого режима «для всех» нет.
- Каждый API-маршрут объявляет действие (`require(Action…)`); тест не даёт добавить маршрут без него.
  Политика `DenyAllPolicy` проверена на всех маршрутах.
- `http` разрешён только для loopback-адресов (тестовые дубли); TLS для реальных хостов не отключается.
- Запись в Confluence (`CONFLUENCE_PUBLISH_ENABLED=true`) блокирует старт.
