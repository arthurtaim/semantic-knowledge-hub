# Задание для Claude Code: SKH UI v2 — новый интерфейс, ассистент с файлами и навыками, карта знаний

Ты начинаешь без контекста предыдущих сессий. Всё нужное есть в репозитории и в папке `ui-v2-handoff/`.
Работай самостоятельно: изучи, реализуй по фазам, проверяй, коммить, отчитывайся. Не останавливайся на плане.

## Цель

Текущий интерфейс выглядит устаревшим и неудобным (`screens/current/`):
- две полосы сверху (тёмно-зелёная навигация и строка поиска);
- линейки вместо поверхностей, подчёркнутые ссылки, засечный шрифт в тексте, нет иконок;
- ассистент — длинная форма, а не диалог;
- граф — нечитаемый «клубок».

Нужно перевести приложение на новый интерфейс по макетам (`screens/design/`) и спецификациям (`specs/`):
- спокойная светлая оболочка уровня приложений Apple, тёмная тема;
- ассистент как главный экран, поле ввода с файлами, навыками и документами (как в Cursor);
- документ с панелью ассистента, каталог-таблица;
- новая карта знаний с перетаскиванием узлов.

Функциональность, маршруты, правила ИИ (доказательства, ревью, режимы) сохраняются.

## 2. Фазы (по порядку; каждая фаза — серия малых коммитов, после фазы — push ветки)

### Фаза A. Визуальная система (`specs/01_VISUAL_SYSTEM.md`)

- Токены как CSS custom properties, светлая и тёмная темы. Тема: системная или выбранная пользователем.
- Шрифт Inter: разрешено добавить зависимость `@fontsource/inter`.
  `@fontsource/golos-text` и `@fontsource/pt-serif` убрать, когда они больше не используются.
- Компонент `Icon` с набором иконок из `design-source/` (inline SVG, без новых библиотек).
- Базовые компоненты: Button (primary / secondary / quiet / icon), SegmentedControl, Chip, StatusMark,
  Popover / Menu, Tooltip. Существующие стили переводятся на токены.
  Старые hex-значения вне токенов не оставлять.

### Фаза B. Оболочка и навигация (`specs/03_SCREENS.md` §1)

- Боковая панель вместо верхней полосы:
  - логотип и рабочее пространство;
  - «Поиск Ctrl K» (существующая палитра ⌘K);
  - пункты Ассистент, Ревью;
  - группы Знания (Документы, Карта знаний, Шаблоны), Работа (Предложения, Публикации), Система
    (Интеграции);
  - внизу пользователь.
- Сворачивание в иконки. На ширине меньше 960 px — выезжающая панель.
- Панель инструментов страницы высотой 52 px: путь или заголовок, действия справа.
- Демо-статус — тихая плашка в панели инструментов. Чип режима ИИ остаётся.

### Фаза C. Ассистент (`specs/02_ASSISTANT.md`)

- Главная = экран ассистента (`design-01/02`).
- `/ask` = диалог (`design-03`): цитаты в тексте, карточка цитаты при наведении, один список источников
  внизу (команда / вложения раздельно), исключённые документы свёрнуты, поле ввода закреплено внизу.
- Компонент `Composer` (один на главной, в диалоге и в панели документа):
  - вложения: кнопка, перетаскивание, вставка;
  - навыки: кнопка и «/»;
  - документы: кнопка и «@»;
  - область поиска; поведение во всех четырёх режимах ИИ.
- Бэкенд (**разрешён в этой фазе**, с тестами): API вложений, реестр навыков и параметры `ask` по контракту
  из `specs/02_ASSISTANT.md` §5. Навыки строятся поверх существующих сценариев M5.6.3
  (`AiProposalKind`), а не заново.

### Фаза D. Документ и каталог (`specs/03_SCREENS.md` §3–4)

- Документ (`design-04`):
  - строка статуса, крупный заголовок, свойства сеткой вместо «паспорта»;
  - сегменты Текст / Связи / История / Markdown;
  - текст документа шрифтом Inter 16/27;
  - панель ассистента справа (кнопка «Ассистент» в панели инструментов и ⌘J), с контекстом «Этот
    документ» и выделением;
  - плавающая панель действий над выделенным текстом.
- Каталог (`design-05`): таблица с группировкой и фильтрами-чипами, переключатель Список / Таблица / Карта.
  Остальные страницы (Шаблоны, Импорт, Предложения, Публикации, Интеграции, Создание документа) — в новой
  системе без смены логики.

### Фаза E. Карта знаний (`specs/04_KNOWLEDGE_GRAPH.md`)

Только фронтенд. API и семантику графа не менять. Перетаскивание узлов обязательно и проверяется тестами.

### Фаза F. Доводка

- Тёмная тема на всех экранах.
- Телефон 390 px.
- Доступность (WCAG 2.2 AA).
- Удаление мёртвых стилей.
- Обновить `docs/UI_REDESIGN.md`: раздел «UI v2» с чек-листом и отклонениями.

## 3. Правила

- Русский UI, идентификаторы на английском. Не выдумывать данные, счётчики и статусы.
- Правила ИИ из `specs/02_ASSISTANT.md` §6 обязательны:
  - сначала доказательства;
  - цитата только с источником;
  - уровни поддержки без процентов;
  - команда, корпоративные источники и вложения не смешиваются;
  - ИИ ничего не применяет сам: всегда draft → diff → review;
  - приложение полноценно при `AI_PROVIDER=disabled`;
  - всё сгенерированное помечено «ИИ».
- Визуально:
  - только токены;
  - одна основная (зелёная) кнопка на вид;
  - без градиентов-украшений, «искр», свечений, капса, стрелок в тексте кнопок;
  - тень только у всплывающих слоёв.
- Новые зависимости: фронтенд — только `@fontsource/inter`; бэкенд — только `pypdf`, `python-docx`,
  `openpyxl` для вложений (`specs/02_ASSISTANT.md` §5). Любая другая — остановись и спроси.
- Маршруты и существующие API-контракты не ломать. Новые эндпоинты — только из `specs/02_ASSISTANT.md` §5.
- Тесты, которые опираются на старые тексты и разметку, обновлять в том же коммите, что и изменение, с
  объяснением в сообщении коммита. Покрытие не уменьшать.
- Безопасность вложений пока описывать в `SECURITY.md` не нужно. Минимальные ограничения из
  `specs/02_ASSISTANT.md` §3 всё равно реализовать.
