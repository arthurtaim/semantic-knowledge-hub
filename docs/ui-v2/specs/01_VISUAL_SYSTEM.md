# 01. Визуальная система

Источник: `screens/design/design-08-visual-system.png`, `design-source/System.dc.html`.

## Принципы

- Поверхности вместо линеек. Боковая панель серо-зелёная, рабочая область белая. Карточки и поля — белые
  с тонкой рамкой.
- Один зелёный — для действий: основная кнопка, ссылки, фокус, выбранное. Статусы — своими тонами.
- «Утверждён» — обычное состояние базы знаний, поэтому тихая печать: значок плюс текст, без заливки.
  Громче показываются исключения: черновик, ревью, устарел.
- Без градиентов-украшений, стекла, «искр» и свечения. Тень только у всплывающих слоёв (меню, карточка
  цитаты, список навыков) и у поля ассистента.
- Ссылки в интерфейсе (названия в списках, пункты меню) без подчёркивания. Подчёркнуты только ссылки
  внутри текста документа и ответа.
- Иконки линейные, 16 px, толщина 1,7–1,8. В каждом пункте навигации и в кнопках-инструментах.

Статусы документов:

| Статус | Форма | Цвет (светлая) |
|---|---|---|
| Утверждён | печать с галочкой, текст обычным цветом | значок `#2E8B57` |
| На ревью | заполненная точка | `#6A50C2`, текст `#4E3A9E` |
| Черновик | пунктирный круг | `#B3740F`, текст `#8A5300` |
| Устарел | короткое тире, текст зачёркнут | `#5F665F` |

Статус всегда передаётся текстом и формой, не только цветом.
Все пары текст/фон проверить инструментом на ≥ 4.5:1; рамки полей и значки на ≥ 3:1.

## Шрифт

- Inter (`@fontsource/inter`, начертания 400/500/600, latin и cyrillic), один шрифт и для интерфейса, и для
  текста документов. PT Serif и Golos убрать. JetBrains Mono оставить только для Markdown-исходника, diff и
  кода.
- Шкала:

| Роль | Размер / интерлиньяж | Вес |
|---|---|---|
| Заголовок экрана | 28/34 (документ 30/36), `letter-spacing: -0.015em` | 600 |
| Раздел документа | 20/28 | 600 |
| Текст документа и ответа | 15–16 / 25–27 | 400 |
| Интерфейс, таблицы | 13.5–14 / 20 | 400 / 500 |
| Подписи, метаданные | 12–12.5 / 17 | 400 |

- Без капса в подписях. Цифры в таблицах: `font-variant-numeric: tabular-nums`. ID документов —
  обычным шрифтом, вторичным цветом.

## Размеры и скругления

- Сетка 4 px. Кнопка 32 px (компактная 28–30), строка таблицы 42 px, пункт навигации 30 px, панель
  инструментов 52 px, боковая панель 248 px, панель ассистента 360–380 px, ширина текста ≤ 700–780 px.
- Скругления: кнопки, поля, чипы — 8 (чипы 7–8); блоки — 12; поле ассистента — 14; всплывающие слои — 12;
  маркер цитаты — 5.
- Тени: всплывающий слой `0 12px 32px rgba(16,24,20,.14)` плюс рамка `#DDE2DD`; поле ассистента
  `0 1px 2px rgba(16,24,20,.04), 0 8px 24px rgba(16,24,20,.06)`. В тёмной теме тени слабее, рамки светлее.
- Фокус: рамка `--accent` и кольцо `0 0 0 3px` с прозрачностью около 25 %. Всегда видим.

## Компоненты (минимальный набор)

- `Button`: `primary` (зелёная заливка, одна на вид), `secondary` (белая с рамкой), `quiet` (без рамки),
  `icon` (с `aria-label`).
- `SegmentedControl`: выбранный сегмент — белый «приподнятый» на сером треке (не зелёная заливка).
- `Chip`: фильтры, вложения, навык (зелёный тон), документ; с кнопкой «убрать».
- `StatusMark`, `CiteMarker`, `SourceBadge`.
- `Popover` / `Menu` / `Tooltip`: клавиатура по APG, Esc, возврат фокуса.
- `Icon`: пути из `design-source/*.dc.html` — поиск, ассистент (облачко), ревью (лоток), документы
  (книга), карта знаний (три узла), шаблоны, предложения (ветки), публикации, интеграции (вилка), файл,
  скрепка, навык (квадрат с косой чертой), @, отправить (стрелка вверх), закрыть, плюс, шеврон, ещё, печать
  «утверждён», часы, информация, загрузка.

## Анимация

- Только как ответ на действие: открытие меню и панели (120–180 мс, ease-out), появление чипа.
- `prefers-reduced-motion`: без сдвигов, только смена прозрачности.
