# 02. Ассистент: диалог, поле ввода, вложения, навыки

Источник: `design-01`, `design-02`, `design-03`, `design-04` (панель), `design-07` (все состояния поля).

## 1. Главная = ассистент (`design-01`, `design-02`)

- Заголовок «Что нужно найти или подготовить?» и одна строка о том, что ответы строятся по документам
  команды с цитатами, а черновики уходят на ревью.
- Поле ввода (`Composer`) по центру, ширина до 760 px.
- Под полем — быстрые навыки: 4 кнопки (Черновик документа, Проверить актуальность, Найти связи, Сравнить с
  файлом). Нажатие ставит навык чипом в поле.
- Ниже два списка без рамок:
  - «Недавние диалоги» (вопрос, навык и число источников или вложение, время). Источник — существующий
    `lib/recentQuestions.ts`.
  - «Ждёт вашего решения» (ревью на пользователе, документы без владельца).
- В режиме `disabled`: заголовок «Что нужно найти?», поле работает как поиск, быстрых навыков нет.

## 2. Диалог (`/ask`, `design-03`)

- Панель инструментов: «Ассистент / {вопрос}», плашка «Демо-данные», «Новый диалог».
- Сообщение пользователя справа, светлый пузырь. Над ним чипы того, что было приложено: навык, файлы,
  документы.
- Ответ ассистента:
  1. Строка «Ассистент», уровень поддержки («Подтверждено источниками» / «Частично подтверждено» /
     «Недостаточно данных»), в демо — «Демо-режим: выдержки без языковой модели».
  2. Текст ответа 15/25 с маркерами цитат. Наведение или фокус на маркере — карточка: номер, документ,
     статус, цитата с подсветкой нужного фрагмента, раздел, область, ревизия. Клик — документ на
     `section_anchor`.
  3. Утверждение без подтверждения подчёркнуто янтарной линией и подписано «Нет подтверждения в
     источниках».
  4. Действия: одна основная (по смыслу ответа, например «Предложить правку в маппинг»), «Открыть
     документ», «Копировать с источниками».
  5. Блок «Источники» (рамка 12): группы «Документы команды», «Корпоративные», «Вложения этого
     диалога». Каждая строка: маркер, название, статус, цитата в одну-две строки. У вложений подпись
     «Файл виден только в этом диалоге и не попадает в базу знаний.» Исключённые документы свёрнуты в
     строку «N документов не использованы: черновики и устаревшие. Показать».
- Цитаты **не дублируются**: объяснение в демо-режиме не повторяет те же выдержки, что в «Источниках».
- Поле ввода закреплено внизу. Навык и вложения из прошлого сообщения остаются чипами, их можно снять.
- Состояния: поток («Ищу источники → Формулирую ответ → Проверяю цитаты»), «Недостаточно данных»
  (карточка из фазы 4 в новой стилистике), ошибка с повтором, конфликт.

## 3. Поле ввода `Composer` (`design-07`)

Один компонент для главной, диалога и панели документа (компактный вариант).

| Элемент | Поведение |
|---|---|
| Чипы над текстом | Навык (зелёный тон, одна штука), файлы, документы. У каждого кнопка «убрать». Backspace в пустом поле снимает последний чип |
| Текст | Плейсхолдер «Спросите, опишите задачу или перетащите файл». Enter — отправить, Shift+Enter — новая строка. Высота растёт до 8 строк |
| «Файл» | Выбор файлов. Также перетаскивание на всё поле (рамка-пунктир и подпись «Отпустите, чтобы прикрепить», число и размер файлов) и вставка из буфера |
| «Навык» и «/» в начале строки | Список навыков: название, описание, право («чтение» серым или «создаёт черновик» янтарным). Поиск по вводу после «/». Enter выбрать, Esc закрыть |
| «Документ» и «@» | Поиск по базе (существующий `/api/search`), строки: название, ID, раздел, статус. Выбранный становится чипом и контекстом |
| «Где искать» | Команда / Корпоративные / Оба. По умолчанию «Команда» |
| Режим ИИ | Подпись справа («ИИ: демо» и т. п.) |
| Отправить | Квадрат 34 px со стрелкой вверх. Выключен, пока файлы читаются или поле пустое без навыка |

Чип файла: значок типа, имя, размер. Состояния: «Читаю…», готово (с описанием: «3 листа»,
«12 страниц», «1 240 строк»), ошибка («формат не поддерживается», «больше 20 МБ», «не удалось
прочитать»).

Ограничения вложений (минимальные, без отдельного раздела в `SECURITY.md` на этом этапе):
- до 10 файлов на диалог, до 20 МБ каждый;
- форматы: md, txt, csv, json, yaml/yml, sql; pdf, docx, xlsx;
- извлекается только текст, исполняемое не принимается;
- файлы видны только в своём диалоге, не индексируются в поиск базы знаний, удаляются по истечении срока
  или по кнопке.

Навык выбран и вопрос пуст — Enter запускает навык, если у навыка `prompt_optional`.

Режимы ИИ:

| Режим | Поле |
|---|---|
| `internal_api`, `claude_cli` | Всё доступно |
| `mock` | Доступны навыки с детерминированной mock-реализацией; остальные в списке выключены с причиной в одну строку. Файлы прикрепляются; ответ — дословные выдержки без выводов, помечен «Демо» |
| `disabled` | Поле = поиск по базе: кнопок «Файл» и «Навык» нет совсем, плейсхолдер «Найти в базе знаний» |

## 4. Навыки

Навык — именованный сценарий с явным правом. Реестр отдаёт бэкенд, фронтенд список не зашивает.
Начальный набор поверх существующих сценариев M5.6.3 (`AiProposalKind`, `backend/app/services/ai_workflows.py`):

| id | Название | Право | Основа | Нужно |
|---|---|---|---|---|
| `answer` | Ответ по базе знаний (по умолчанию) | чтение | `ask` | вопрос |
| `explain` | Объяснить | чтение | `explain` | документ или выделение |
| `summarize` | Кратко пересказать | чтение | `summarize` | документ |
| `check_completeness` | Проверить полноту | чтение | `check_completeness` | документ |
| `check_freshness` | Проверить актуальность | чтение | `impact_analysis` | документ |
| `find_related` | Найти связи | чтение | `find_related` / `explain_relation` | документ или вопрос |
| `compare_with_file` | Сравнить с файлом | чтение | новый: ask с вложениями | вложение |
| `draft_document` | Черновик документа | создаёт черновик | `draft_from_prompt` | описание |
| `improve_section` | Улучшить раздел | создаёт черновик | `improve_section` | документ и раздел |
| `suggest_metadata` | Предложить метаданные | создаёт черновик | `suggest_metadata` | документ |

Навык с правом «создаёт черновик» никогда не применяет изменения. Результат — существующее AI-предложение
(`/api/ai/proposals`) с принятием по пунктам или черновик на ревью. Ответ в диалоге показывает карточку
предложения со ссылкой.

## 5. Контракты API (новое; существующее не ломать)

```
GET  /api/assistant/skills
  → [{ id, name, description, access: "read" | "draft",
       requires: { document?: bool, selection?: bool, attachment?: bool },
       prompt_optional: bool, available: bool, unavailable_reason: string | null }]

POST /api/assistant/attachments            multipart: file, conversation_id
  → { id, conversation_id, name, size, mime, status: "ready" | "error",
      summary: string | null,      // «3 листа», «12 страниц», «1 240 строк»
      error_code: "unsupported_type" | "too_large" | "limit_reached" | "unreadable" | null,
      expires_at }
DELETE /api/assistant/attachments/{id}

POST /api/assistant/ask  (и /ask/stream) — новые необязательные поля:
  conversation_id, skill_id, attachment_ids: string[], context_document_ids: string[], selection: { document_id, section_anchor, text } | null
Citation — новый source_type "attachment" с attachment_id, attachment_name, locator («строка 1», «стр. 4», «лист Fields, строка 12»).
```

Бэкенд проверяет:
- навык доступен в текущем режиме;
- вложения принадлежат диалогу и не просрочены;
- цитата из вложения указывает на реально существующий фрагмент.

Тесты: pytest на каждый эндпоинт и ошибки, плюс vitest и e2e на поле ввода в `mock` и `disabled`.

Для pdf, docx и xlsx разрешено добавить в бэкенд `pypdf`, `python-docx`, `openpyxl` (с закреплёнными
версиями в lock-файле). Если что-то не ставится — эти форматы возвращают `unsupported_type`, и это
записывается в отчёт.

## 6. Правила ИИ (не меняются)

1. Сначала доказательства; маркер цитаты только при проверенном источнике.
2. Поддержка — категорией, без процентов.
3. Команда, корпоративные источники и вложения не смешиваются в одном списке; у каждой цитаты видно, откуда она.
4. Ничего не применяется само: draft → diff → review.
5. У каждого ИИ-действия есть ручной путь; при `disabled` приложение полноценно.
6. Всё сгенерированное помечено «ИИ»; демо помечено «Демо».
7. Никаких проактивных подсказок; ассистента открывает пользователь.
