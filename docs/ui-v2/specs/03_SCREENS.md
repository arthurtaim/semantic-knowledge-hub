
- Боковая панель 248 px, фон `--bg-sidebar`, пункты 30 px с иконкой. Активный пункт — серая подложка, без
  зелёной заливки. Счётчики справа вторичным цветом; «Ревью» — зелёный бейдж.
- «Поиск Ctrl K» открывает существующую палитру ⌘K / `/` (фаза 4), стиль — новый.
- Сворачивание в колонку иконок (кнопка и сочетание клавиш). На ширине меньше 960 px — выезжающая панель
  по кнопке в панели инструментов (Esc, возврат фокуса, затемнение фона).
- Панель инструментов 52 px на каждой странице: путь или заголовок слева, действия справа (не больше одной
  основной кнопки), плашка «Демо-данные» (`--demo-*`), чип режима ИИ.
- Ширина содержимого: текст и диалог ≤ 760–780 px по центру; таблицы и граф — во всю ширину.
- Маршруты не меняются. Сопоставление пунктов: Ассистент `/` и `/ask`; Ревью — `/proposals` с фильтром
  «на мне» (если фильтра нет, ведёт в `/proposals`); Документы `/documents`; Карта знаний `/graph`;
  Шаблоны `/templates`; Предложения `/proposals`; Публикации — существующие страницы публикаций (если
  отдельного списка нет, пункт ведёт туда, где они видны сейчас); Интеграции `/integrations`.

## 3. Документ (`design-04`)

- Панель инструментов: путь «Документы / Раздел / Название», «Предложить изменение» (secondary),
  «Ассистент» (переключатель панели, нажатое состояние — зелёный тон), меню «Ещё».
- Над заголовком строка: печать статуса, ID, «Демо-документ» (если демо).
- Заголовок 30/36. Под ним свойства сеткой в две колонки (Владелец, Раздел, Проверен, Источник, Ревизия,
  Связи), разделитель снизу. Старый «паспорт» в рамке убрать; все его поля сохранить (часть — в «Ещё»
  или во вкладке).
- Сегменты: Текст / Связи / История / Markdown (существующие вкладки: метаданные, ссылки, публикация —
  разложить по этим сегментам или в правую панель «Сведения»).
- Текст документа: Inter 16/27, ширина ≤ 700 px. Повторяющийся H1 из Markdown не показывать.
- Выделение текста — тёмная плавающая панель «Объяснить / Найти связанные / Предложить правку» (навыки
  `explain`, `find_related`, `improve_section` с контекстом выделения). Клавиатура: появляется и при
  выделении с клавиатуры; Esc закрывает.
- Панель ассистента справа 360–380 px (⌘J / Ctrl+J и кнопка):
  - контекст чипами: «Этот документ», «Выделение: N строк»;
  - быстрые действия списком;
  - короткая переписка;
  - компактный `Composer`.
  
  По умолчанию закрыта, состояние запоминается. Меньше 1200 px — выезжающий лист.
- Публикация в Confluence, блок ИИ-предложений, связи и WikiLinks — сохранить, перенести в новую сетку.

## 4. Каталог (`design-05`)

- Панель инструментов: «Документы 83», сегменты Список / Таблица / Карта (Карта ведёт на `/graph` с теми же
  фильтрами), поле «Найти в списке», «Создать документ» (primary).
- Строка фильтров: чипы активных фильтров («Статус: Утверждён, На ревью ×»), «+ Фильтр» (меню фасетов из
  текущей левой колонки), справа «Группировка: Раздел» и «Вид».
- Таблица: Название (жирный 500) с ID вторичным цветом, Статус (форма и текст), Владелец, Обновлён, Связи.
  Строка 42 px, заголовки групп 36 px с числом. Строка целиком кликабельна (ссылка на названии).
- «Список» — текущий вид с фрагментами текста, в новой стилистике. Выбор вида запоминается.
- Телефон: таблица превращается в список карточек-строк, фильтры — в выезжающий лист.

## 5. Остальные страницы

Перевести на новую систему без изменения логики, в той же логике «панель инструментов, содержимое, правая
панель»:
- Шаблоны и шаблон, Импорт документа, Создание документа (мастер: шаги — как сегменты или степпер в новой
  стилистике), Предложения и предложение (diff, правая панель действий), Публикация, Корпоративная
  страница, Интеграции (список с состояниями), 404.

Скриншоты текущего вида — в `screens/current/`.
