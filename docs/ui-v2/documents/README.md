# Раздел «Документы» v2: пакет для Claude Code

Дерево как в Confluence (разделы → группы → документы) со списком ветки и предпросмотром, обзор «разделы ×
состояние», плотная таблица. Продолжение UI v2 (`docs/ui-v2/`).

## Как пользоваться

1. Папка уже должна лежать в корне репозитория как `docs-v2-handoff/`. Если нет — распакуйте туда архив.
2. В новой сессии Claude Code: «Выполни задание из `docs-v2-handoff/TASK.md`».

## Что внутри

| Путь | Что это |
|---|---|
| `TASK.md` | Задание: ветка `feature/documents-v2` от `main`, срезы, правила, проверка, отчёт |
| `specs/DOCUMENTS_V2.md` | Спецификация: три вида, дерево и клавиатура, правило групп, новый API `/api/documents/tree`, тесты |
| `screens/design/` | Макеты (PNG, 2×) |
| `screens/current/` | Как раздел выглядит сейчас в `main` |
| `design-source/` | Исходники макетов (`.dc.html`): точные цвета, размеры, тексты. Не код приложения |

| Макет | Экран |
|---|---|
| `docs-01-tree-list-preview.png` | Список: дерево раскрыто до «Интеграции / ARIS», выбран документ, предпросмотр |
| `docs-02-tree-attention.png` | Выбрано «Требуют внимания», раскрыты «Системы-источники», документ на ревью |
| `docs-03-overview-matrix.png` | Обзор: разделы × состояние, «Что сделать» |
| `docs-04-table.png` | Таблица: фильтр «Только требующие внимания», сортировка по дате проверки |

Группы в макете условные; верна раскладка по правилу из `specs/DOCUMENTS_V2.md` §4. В макете списка ветки
надпись «показаны первые 11» — ограничение макета; в приложении список без обрезки.
