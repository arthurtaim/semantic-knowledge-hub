# Планировщик v2: пакет для Claude Code

Страница проекта (M6 «Работа»):
- компактный каркас;
- диаграмма Ганта с масштабами День–Год и «Вписать», адаптивной шкалой, подписями без наложений и стрелками по
  промежуткам;
- список задач без выпадающих списков в каждой ячейке.

Только фронтенд. Продолжение UI v2 (`docs/ui-v2/`).

## Как пользоваться

1. Папка уже должна лежать в корне репозитория как `planner-v2-handoff/`. Если её нет — распакуйте туда
   архив.
2. В новой сессии Claude Code: «Выполни задание из `planner-v2-handoff/TASK.md`».

## Что внутри

| Путь | Что это |
|---|---|
| `TASK.md` | Задание: ветка `feature/planner-v2` от `main`, срезы, правила, проверка, отчёт |
| `specs/PLANNER_V2.md` | Спецификация: проблемы, каркас, масштабы и шкала, полосы и сводные задачи, подписи, стрелки, «Вид», список, решения владельца, тесты; §9 — следующая задача (бэкенд) |
| `screens/design/` | Макеты (PNG, 2×) |
| `screens/current/` | Как страница выглядит сейчас в `main` (`1377ee6`) |
| `design-source/` | Исходники макетов (`.dc.html`). В `PlanGantt.dc.html` в `renderVals()` — эталонная логика шкалы, подписей и стрелок. Это не код приложения |

| Макет | Экран |
|---|---|
| `plan-01-gantt-week.png` | Неделя. Выбрана просроченная ARIS-6 (штриховка до сегодня), её связи выделены; сводные задачи — «скобкой» по подзадачам |
| `plan-02-gantt-day.png` | День. Задачи левее окна — метками `‹ 2 нояб. – 9 нояб.`, подписи прижаты к краю |
| `plan-03-gantt-fit.png` | «Вписать»: весь проект по ширине |
| `plan-04-gantt-month.png` | Месяц: шкала «квартал / месяцы», связи только у выбранной |
| `plan-05-gantt-quarter.png` | Квартал |
| `plan-06-gantt-year.png` | Год: подписи читаются, стрелки скрыты |
| `plan-07-gantt-view-menu.png` | Меню «Вид»: связи, подписи, клавиши |
| `plan-08-list-grouped.png` | Список, группировка по статусу, меню статуса открыто по клику |

Данные в макетах — синтетический демо-проект ARIS. Ширина подписей в макете оценена приблизительно; в
приложении её нужно мерить.
