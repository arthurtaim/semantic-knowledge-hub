# SKH UI v2: пакет для Claude Code

Новый интерфейс Semantic Knowledge Hub: оболочка в духе приложения для Mac, ассистент как главный экран,
поле ввода с файлами, навыками и документами, документ с панелью ассистента, каталог-таблица, новая карта
знаний с перетаскиванием узлов.

## Как пользоваться

1. Распакуйте архив в корень репозитория `semantic-knowledge-hub` как папку `ui-v2-handoff/`.
   Её содержимое агент первым коммитом перенесёт в `docs/ui-v2/`.
2. В новой сессии Claude Code напишите: «Выполни задание из `ui-v2-handoff/TASK.md`».

## Что внутри

| Путь | Что это |
|---|---|
| `TASK.md` | Задание агенту: ветка, порядок фаз, правила, проверка, отчёт. **Начинать отсюда.** |
| `specs/01_VISUAL_SYSTEM.md` | Токены (светлая и тёмная темы), шрифт, иконки, скругления, слои, статусы |
| `specs/02_ASSISTANT.md` | Диалог, поле ввода, вложения, навыки, «@документ», режимы ИИ, контракты API |
| `specs/03_SCREENS.md` | Оболочка, главная, ответ, документ с панелью, каталог, остальные страницы |
| `specs/04_KNOWLEDGE_GRAPH.md` | Карта знаний: внешний вид, перетаскивание узлов, раскладка, проверки |
| `screens/design/` | Макеты нового интерфейса (PNG, 2×) |
| `screens/current/` | Как интерфейс выглядит сейчас в `main` (до изменений) |
| `design-source/` | Исходники макетов (`.dc.html`): точные цвета, размеры, тексты. Это не код приложения |
