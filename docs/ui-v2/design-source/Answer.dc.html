Что отправляет ARIS в каталог? И совпадает ли моя выгрузка с утверждённым маппингом?
Ассистент Частично подтверждено Демо-режим: выдержки без языковой модели

ARIS передаёт в каталог выгрузку в формате JSON Lines: одна строка на объект, шесть полей1. Это поля aris_object_guid, aris_object_name, aris_model_path, aris_owner_role, aris_last_change и aris_status2. Пакет содержит до 500 записей, глубина модели не больше 73.

В вашем файле семь колонок. Колонка aris_comment в утверждённом маппинге не описанаФ1. Остальные шесть совпадают по названию.

Куда каталог записывает принятые объекты, в документах команды не сказано. Нет подтверждения в источниках
