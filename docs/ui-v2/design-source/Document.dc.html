This local demonstration models a knowledge base with four layers: a document repository, an indexing service, a search API and a user interface. These are application concepts for demo and testing, not statements about corporate architecture.

Principles

  • A document always has a stable ID and an approval status.
  • Search results reference their source document.
  • Suggested changes require human review.

Layers

The repository stores Markdown documents with front-matter. The indexing service builds a full-text index; the search API returns passages with their document, section and revision.
